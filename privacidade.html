Política de Privacidade

Última atualização: versão 1.0

1. Quais dados coletamos

Coletamos apenas o essencial para o Drops funcionar:

  • Nome, data de nascimento e e-mail
  • Nome de usuário único (@)
  • Localização precisa (latitude e longitude) — usada para mostrar pessoas e publicações próximas a você
  • Conteúdo que você publica (fotos, vídeos, mensagens, áudios, documentos)
  • Dados de uso técnico (endereço IP, tipo de navegador, sistema operacional)

2. Como usamos seus dados

  • Permitir que você use o app
  • Mostrar pessoas e publicações próximas a você (com base na localização precisa)
  • Verificar sua identidade
  • Enviar códigos de segurança por e-mail
  • Moderar conteúdo e processar denúncias
  • Melhorar a experiência do app

3. Compartilhamento com terceiros

Não vendemos seus dados. Compartilhamos apenas com prestadores de serviço essenciais:

  • Supabase — banco de dados e autenticação (armazena perfil, mensagens, publicações)
  • Cloudflare R2 — armazenamento de mídia (fotos e vídeos publicados)
  • Nominatim / OpenStreetMap — conversão de coordenadas em endereço legível (geocodificação reversa)

Todos os prestadores atuam sob contratos de confidencialidade e processam dados apenas para as finalidades acima.

4. Retenção de dados

  • Mensagens apagadas por você ou pelo destinatário são removidas em até 30 dias
  • Conta excluída: todos os dados pessoais são removidos em até 30 dias
  • Denúncias são mantidas por até 12 meses para fins de moderação

5. Seus direitos (LGPD)

Conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018), você tem direito a:

  • Acessar seus dados a qualquer momento
  • Corrigir dados incorretos
  • Solicitar a exclusão dos seus dados
  • Revogar o consentimento (inclusive o de localização precisa)
  • Solicitar a portabilidade dos dados
  • Ser informado sobre compartilhamento com terceiros

Para exercer qualquer direito, use a página Exclusão de Conta ou envie e-mail para dpo@drops.app.

6. Segurança

Usamos criptografia em trânsito (HTTPS) e controles de acesso no banco de dados. Nenhum sistema é 100% seguro — avise-nos imediatamente se suspeitar de acesso indevido.

7. Encarregado de Dados (DPO)

Para exercer seus direitos ou tirar dúvidas sobre privacidade: dpo@drops.app

8. Alterações nesta política

Podemos atualizar esta política periodicamente. Mudanças importantes serão avisadas dentro do app antes de entrar em vigor.
